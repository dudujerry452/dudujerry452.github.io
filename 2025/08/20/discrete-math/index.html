从集合论到置换群

发表于2025-08-20|更新于2026-08-19
|总字数:3.1k|阅读时长:12分钟

集合论

集合运算满足

  • 交换、结合、分配律
  • 幂等律
  • 徳摩根律
  • 吸收律 A∩(A∪B)=A,A∪(A∩B)=AA\cap (A\cup B) = A, A\cup(A\cap B) = AA∩(A∪B)=A,A∪(A∩B)=A

关系

五大性质:

  • 自反
  • 对称
  • 传递
  • 反自反
  • 反对称

其中, 只有自反不是if…, then …格式.

复合/逆关系

满足结合律, 不满足交换律.

笛卡尔积的复合还是笛卡尔积.

(R∘S)−1=S−1∘R−1(R\circ S)^{-1} = S^{-1} \circ R^{-1}(R∘S)−1=S−1∘R−1

自反和传递的集合S有S∘S=SS \circ S = SS∘S=S

关系闭包

  • r(R)=R∪IAr(R) = R\cup I_Ar(R)=R∪IA​
  • s(R)=R∪R−1s(R) = R\cup R^{-1}s(R)=R∪R−1
  • t(R)=⋃i=1∞Rit(R) = \bigcup_{i=1}^{\infty}R^it(R)=⋃i=1∞​Ri, 对于有限集t(R)=⋃i=1nRit(R) = \bigcup^{n}_{i=1}R^it(R)=⋃i=1n​Ri

除了满足传递性的集合的对称闭包不传递, 其他满足性质X的集合的各种闭包都满足性质X.

等价关系

Def. 满足自反, 对称, 传递的关系

模m同余关系 m∣(i−j)⇔iRmj⇔i≡j mod mm | (i-j)\Leftrightarrow iR_mj \Leftrightarrow i\equiv j\ mod\ mm∣(i−j)⇔iRm​j⇔i≡j mod m

等价关系的交集, 等价关系的并集的传递闭包还是等价关系.

Def. 等价类构成的集合称为商集 {[a]R∣a∈A}=A/R\{[a]_R | a\in A\} = A/R{[a]R​∣a∈A}=A/R

等价类性质:

  • a∈[a]a\in [a]a∈[a]
  • [a]=[b]⇔aRb[a] = [b] \Leftrightarrow aRb[a]=[b]⇔aRb
  • [a]∩[b]=∅⇔aRb[a] \cap [b] = \empty \Leftrightarrow a\cancel{R}b[a]∩[b]=∅⇔aR​b

Def. 划分, 当集合族满足⋃i∈JCi=A\bigcup_{i\in J} C_i = A⋃i∈J​Ci​=A且Ci∩Cj=∅C_i \cap C_j = \emptyCi​∩Cj​=∅, 则称{Ci∣i∈J}\{C_i| i \in J\}{Ci​∣i∈J}为AAA的一个划分.

  • 划分必定是覆盖
  • 划分和等价关系可以互推有无
  • 商集相同则对应的等价关系相同

偏序关系

Def. 满足自反, 反对称, 传递的称为偏序关系.

  • 整除关系是偏序关系

盖住: a<ba < ba<b且不存在c 使得a<c<ba < c < ba<c<b

Hasse图: 向上表示盖住

Def. 两两元素可比较的是全序关系. 集合称为全序集.

Def. 偏序集的子集若为全序集, 则称为链

极大&极小元

Def. ∀x∈P,s.t.a≤x\forall x\in P, s.t. a \leq x∀x∈P,s.t.a≤x, 则a为最小元.

Def. ∃x∈P,s.t.x<a\cancel{\exist}x\in P, s.t. x < a∃​x∈P,s.t.x<a, 则称a为极小元

  • 极大元(无限下降链), 最大元都可能不存在.
  • 最大元存在则必唯一, 且为唯一极大元
  • 有限集中‾\underline{有限集中}有限集中​, 极大元存在且唯一时为最大元.

上界&最小上界

上界, 最大上界未必存在, 但最大上界存在即唯一.

  • 恒等关系
  • 投影函数 笛卡尔积的逆操作
  • 特征函数 在集合的为1, 不在集合的为0
  • 自然映射 代表元映射到商集

函数

左复合: g∘f(a)=g(f(a))g\circ f(a) =g(f(a))g∘f(a)=g(f(a))

关系的复合满足结合律

若两个关系满足双射,满射 ,和单射那么复合之后仍然是双射, 满射和单射

函数可逆⇔\Leftrightarrow⇔函数是双射

集合的势

Def. 如果存在集合A到集合B的双射, 说明A与B等势

  • 有限集等势, 说明二者元素相同多
  • 等势是一个等价关系
  • 两个集合族中集合一一等势, 则它们的并也等势
  • 无限集必定与其真子集等势

Def. 若A∼BA\cancel{\sim}BA∼​B, 且A与B的某子集等势, 记为∣A∣≤∣B∣|A| \leq |B|∣A∣≤∣B∣

  • ∣A∣≤∣B∣⇔存在A到B的单射|A| \leq |B|\Leftrightarrow 存在A到B的单射∣A∣≤∣B∣⇔存在A到B的单射

  • 集合势的≤\leq≤是一偏序关系

  • 对任意集合∣A∣<∣2A∣|A| < |2^A|∣A∣<∣2A∣ (证明 先由单射确认∣A∣≤∣2A∣|A| \leq |2^A|∣A∣≤∣2A∣, 再证明∣A∣∼∣2A∣|A| \cancel{\sim} |2^A|∣A∣∼​∣2A∣)

Def. 与自然数集N等势的集合称为可数集.

  • 对任意集合A, 当且仅当A的元素可不重复地排列成一个无穷序列a0,a1,a2,...,an,...a_0, a_1, a_2, ..., a_n, ...a0​,a1​,a2​,...,an​,...时, A为可数集.
  • 可数集的无穷子集必为可数集
  • 任何无限集必有可数子集
  • 可数集加入/删除有限个元素, 仍为可数集.
  • 一列可数集(有限或无限)之并为可数集
  • 可数集的笛卡尔积是可数集
  • 无限集与可数集/有限集之并与其等势

代数系统

Def. 设A为一个集合, AxA到A的映射称为A上的二元运算.

  • 数的加法是实数集上的二元运算
  • 数的除法不是实数集上的二元运算, 但是是R−{0}R-\{0\}R−{0}上的.
  • 集合的并和交是P(S)上的二元运算

运算性质术语:

  • 可结合的
  • 可交换的
  • 左/右分配律
  • 左/右消去律

Def. 非空集合上的运算称为代数系统.

Def. 如果代数系统的子集满足运算的封闭性, 则称为子代数

单位元

  • 如果一个运算系统既有左单位元ele_lel​, 也有右单位元ere_rer​, 则存在单位元el=ere_l = e_rel​=er​
  • 单位元若存在则唯一

逆元

在<A, *>中, 对于a∈A,如果存在b∈A,s.t.ba=ea \in A, 如果存在b\in A, s.t. ba = ea∈A,如果存在b∈A,s.t.ba=e, 则称b是a的左逆元

左右逆元b1=b2=a′b_1=b_2=a'b1​=b2​=a′相等, 则称a是可逆的, 并且a’是a的逆元.

  • 如果代数系统的运算满足结合律, 则左右逆元相等, 且逆元唯一

Def. 若a*a = a则a为代数系统下的幂等元.

  • 单位元若存在必定为幂等元.

同态与同构

Def. 设两代数系统<A, *>, <B, ∘\circ∘>为两个代数系统, 设f:A→Bf: A\rightarrow Bf:A→B, 如果f保持运算, 即

f(x∗y)=f(x)∘f(y)\notag f(x*y) = f(x)\circ f(y) f(x∗y)=f(x)∘f(y)

则两代数系统同态. f为A到B的同态映射.

  • 零同态: f:a∣→e,∀a∈Af:a | \rightarrow e, \forall a\in Af:a∣→e,∀a∈A
  • f是单射: 单同态
  • f是满射: 满同态
  • f是双射: 同构, 记作A≅BA\cong BA≅B
  • 同态映射的复合仍为单同态、满同态、同构.
  • 同态映射的逆函数仍是同态映射.

同态的运算性质保持:

  • 满同态保持结合律
  • 满同态保持交换律
  • 满同态保持单位元
  • 满同态保持逆元
  • 同态保持幂等元

Def. 到自身的同态称为自同态, 到自身的同构称为自同构.

同余关系与商代数

同余关系

Def. E是A上的等价关系, ∀x1,x2,y1,y1∈A,当x1Ey1,x2Ey2时,x1∗x2Ey1∗y2\forall x_1, x_2, y_1, y_1\in A, 当x_1 E y_1, x_2 E y_2时, x_1*x_2 E y_1*y_2∀x1​,x2​,y1​,y1​∈A,当x1​Ey1​,x2​Ey2​时,x1​∗x2​Ey1​∗y2​, 此时称E为A上的同余关系.

Def. <A/R, ∘\circ∘>上满足[x]∘[y]=[x∗y][x] \circ [y] = [x*y][x]∘[y]=[x∗y], 此时要求E是<A, *>上的同余关系.

据此可以定义, ϕ(x)=[x]\phi(x) = [x]ϕ(x)=[x]是一个同态, 即ϕ(x)∘ϕ(x)=ϕ(x∗y)\phi(x) \circ \phi(x) = \phi(x*y)ϕ(x)∘ϕ(x)=ϕ(x∗y), 是<A, *>到<A/E, ∘\circ∘>的自然同态.

xEfy⇔f(x)=f(y),∀x,y∈AxE_f y \Leftrightarrow f(x) = f(y), \forall x, y \in AxEf​y⇔f(x)=f(y),∀x,y∈A

则EfE_fEf​是A上的同余关系. (证明: 先证等价, 再证性质)

半群

Def. 若<S,∘><S, \circ><S,∘>为一代数系统, 运算满足结合律, 则则称其为半群.

  • an=a∘a∘a...∘aa^n = a\circ a\circ a... \circ aan=a∘a∘a...∘a
  • aman=am+na^ma^n = a^{m+n}aman=am+n
  • (am)n=amn(a^m)^n = a^{mn}(am)n=amn

当半群的乘法满足交换律时, 称为可交换半群, 此时有(ab)n=anbn(ab)^n = a^nb^n(ab)n=anbn

Def. 若半群中存在单位元, 则为幺半群.

  • 幺半群S中, 若a∈Sa\in Sa∈S的逆元存在, 则唯一(满足结合律), 用a−1a^{-1}a−1表示.
  • (a−1)−1=a(a^{-1})^{-1} = a(a−1)−1=a
  • a−1a=ea^{-1}a = ea−1a=e

Def. 若半群S的子集T在运算∘\circ∘下也构成半群(T⊆ST \subseteq ST⊆S在运算∘\circ∘上封闭), 称T为子半群.

Def. 若幺半群S的子群T有S的单位元e∈Te\in Te∈T, 则称T是S的子幺半群. (a0=ea^0 = ea0=e)

群

Def. 如果一个幺半群满足所有元素都有逆元, 则称为群.

Def. 如果一个群满足交换律, 则称为交换群或Abel群.

设G为群

  • G中消去律成立
  • 单位元e是唯一幂等元.

设fff是G到H的同态

  • f(e)f(e)f(e)是H的单位元
  • ∀a∈G,f(a)−1=f(a−1)\forall a\in G, f(a)^{-1} = f(a^{-1})∀a∈G,f(a)−1=f(a−1)

群有如下判定:

  • G是群, 若存在G到H的满同态, 则H必为群
  • 若G是一个半群, 且有左单位元和∀a∈G\forall a\in G∀a∈G存在左逆元a−1a=ea^{-1}a = ea−1a=e, 则G为群
  • 若半群中对∀a,b∈G,方程ax=b,ya=b总有解\forall a,b \in G, 方程ax=b, ya=b总有解∀a,b∈G,方程ax=b,ya=b总有解, 则G是一个群.
  • 若消去律成立, 则有限半群是一个群.

若G是一个有限群, 则运算表中每一行(列)都是G中元素的一个全排列.

子群和周期

Def. 如果G是一个群, 其子集在运算下也构成群, 称为子群. 除了{e}和G的称为真子群.

G是群, H是G的子群:

  • H的单位元就是G的单位元
  • H中任意元素的逆元就是G中元素的逆元

H是G的非空子集. 当且仅当

  • ∀a,b∈H,a∗b∈H\forall a,b \in H, a*b \in H∀a,b∈H,a∗b∈H
  • ∀a∈H,a在G中的逆元a−1∈H\forall a\in H, a在G中的逆元a^{-1}\in H∀a∈H,a在G中的逆元a−1∈H

时, H是G的子群.

  • 推论: ∀a,b∈H,a∗b−1∈H⇔H是G的子群\forall a,b \in H, a*b^{-1} \in H \Leftrightarrow H是G的子群∀a,b∈H,a∗b−1∈H⇔H是G的子群.

循环子群

Def. G为群,a∈G,∃n∈Z+,s.t. an=e,称满足该条件的最小正整数为a的周期∣a∣,否则为∞G为群, a\in G, \exist n\in Z^+, s.t.\ a^n = e, 称满足该条件的最小正整数为a的周期|a|, 否则为\inftyG为群,a∈G,∃n∈Z+,s.t. an=e,称满足该条件的最小正整数为a的周期∣a∣,否则为∞

设G为群, a∈Ga\in Ga∈G

  • |a| = |(a)|, a的周期等于其生成的循环子群的阶
  • 若a的周期为n<∞n<\inftyn<∞, 则am=e⇔n∣ma^m = e \Leftrightarrow n|mam=e⇔n∣m

循环群

Def. G为一个群, a∈Ga\in Ga∈G, 且G=(a)={ai∣i∈Z}G = (a) = \{a^i | i\in Z\}G=(a)={ai∣i∈Z}, 称为G为由a生成的循环群, 称a为其生成元.

设G是一个循环群.

  • 若G是无限群, 则<G,∗>≅<Z,+><G, *> \cong <Z, +><G,∗>≅<Z,+>
  • 若G是有限群, 周期是n, 则<G,∗>≅<Zn,+n><G, *>\cong <Z_n, +_n><G,∗>≅<Zn​,+n​>

设G是一个循环群,

  • G的子群必为循环群
  • 设G是n阶循环群, m是正整数且m|n, 则G中存在唯一一个m阶子群.
  • G必为Abel群.

置换群

Def. 有限集S到自身的双射称为S上的置换, 当|S| = n时称为n次置换.

Def. 对集合中的一部分x1,x2,x3...xdx_1, x_2, x_3... x_dx1​,x2​,x3​...xd​, 映射x1→x2,x2→x3...,xd→x1x_1 \rightarrow x_2, x_2\rightarrow x_3..., x_d\rightarrow x_1x1​→x2​,x2​→x3​...,xd​→x1​, 称为循环置换.

d=2时称为对换; d=1时为恒等映射, 也叫单位置换, (1), (n).

Def. 有限集S = {1,2,3,4 …, n}, 其上所有n次置换构成的集合SnS_nSn​称为n次对称群, 其子群称为n次置换群.

  • SnS_nSn​是群.
  • (Cayley定理) 任意n阶群必定同构与一个n次置换群
