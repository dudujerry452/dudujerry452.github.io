请注意，不同版本前缀[graphical/minimal]指的是安装时的LiveCD是否带有桌面环境，与安装后的桌面环境无关；如果不是实在没办法，建议选择命令行安装，因为目前图形化界面不支持切换安装源，导致在境内部分网络下安装极其缓慢。

烧录好安装介质后，在Boot Menu界面进入安装器，graphical界面会弹出，只需要根据图形界面提示操作即可，注意分区谨慎操作。这里主要讲命令行安装。

命令行安装 ​

如果你使用WiFi（以太网安装可忽略该部分）：

切换到root用户，输入

sh
systemctl start wpa_supplicant
wpa_cli
> add_network
0
> set_network 0 ssid "myhomenetwork"
OK
> set_network 0 psk "mypassword"
OK
> set_network 0 key_mgmt WPA-PSK
OK
> enable_network 0
OK

如果看到connect字样说明链接成功。

接下来分区，请谨慎操作, 假设硬盘设备名称为/dev/sda(如果在虚拟机上安装，可能是/dev/vda)：

sh
gdisk /dev/sda # 启动分区程序

> n # 添加新分区
> # 回车一直到last sector 
> +512M # 为第一个分区设置大小为512M的空间
> ef00 # 表明这是UEFI启动分区

> n
> # 一直到last sector 
> +8G
> 8200 # 表明这是交换区，可根据内存大小自行设置

> n 
> # enter直到创建完成

> w # 写入分区表

分区完成后，可用lsblk -f /dev/sda查看分区情况，假设分好的区为/dev/sda1, /dev/sda2, /dev/sda3

接下来格式化：

sh
mkfs.vfat /dev/sda1 # 格式化UEFI引导区为vfat  

mkfs.xfs /dev/sda3 # 格式化主存储区为xfs 

mkswap /dev/sda2 
swapon /dev/sda2 # 创建和指定交换分区

mount /dev/sda3 /mnt 
mount /dev/sda1 /mnt/boot # 挂载分区 

passwd root # nixos-generate-config 和nixos-install 会将这里设置的root密码迁移到完整系统，所以先设置root密码

nixos-generate-config --root /mnt # 生成nixos硬件配置文件

# 此时，可在/etc/nixos/configuration.nix中修改配置来打开ssh等，注意这里的所有设置都只限于LiveCD的设置，与安装好的系统没关系 

nixos-install --option substituters https://mirrors.ustc.edu.cn/nix-channels/store # 国内一定要用镜像源安装。否则卡46%，非常慢。如果还是很慢，说明该国内镜像缺少一些二进制缓存，需要重新编译，这时就需要切换成别的镜像，详见https://help.mirrors.cernet.edu.cn/nix-channels/ 

umount /mnt  # 安装完成后，取消挂载

reboot # 重启即可

重启后，系统从UEFI启动，我们可以看到崭新的NixOS系统。如果没有选择Minimal安装，这里会进入一个无效的登录界面，即输入密码正确后也显示Failed to start session。这是因为我们没设置桌面环境，按Ctrl+Alt+F4进入tty4，用root账户登录（之前设置的root密码），修改/etc/nixos/configuration.nix，添加

nix
nix.settings.substituters = lib.mkForce [ "https://mirrors.ustc.edu.cn/nix-channels/store" ]; # 更换软件源

services.displayManager.sddm.enable = true; # 启用sddm作为登录窗口管理器
services.displayManager.plasma6.enbale = true; # 打开plasma6桌面环境，也可选择gnome等
 
# 下面这两段的注释，按需修改

users.users.yourusername = { # 声明你的用户，替换yourusername为用户名字
  isNormalUser = true;
  extraGroups = [ "wheel" ]; # 放到sudo组里
  packages = with pkgs; [
    tree
  ];
};

environment.systemPackages = with pkgs; [
  vim # 安装一些常用的软件
  wget
  git
  neofetch # 方便让你的朋友们看到大大的NixOS图标
  htop
];

修改完后，输入

sh
nixos-rebuild switch 
nixos-rebuild boot & reboot

即可切换到新版本系统，并看到美丽的plasma6啦。

Tips ​

  • NixOS对系统纯净度要求极高，导致不存在默认链接器(比如/lib64/ld-linux-x86-64.so.2)，这会导致许多预编译的二进制文件原地爆炸，比如vscode-server。要想通过remote-ssh插件连到一台nixos机器上，需要安装nodejs，并且设置programs.nix-ld.enable = true;来允许第三方二进制文件运行。

  • 这也意味着像npm, pipx等全局安装的包管理器无法写入/etc/nixos/store，所以安装npm包最好的方式是:

    sh
    mkdir -p ~/.npm-global
npm config set prefix '~/.npm-global'
echo 'export PATH=~/.npm-global/bin:$PATH' >> ~/.bashrc
npm install -g yourpackage

    即创建一个本地目录假装这是全局包存储目录。

  • 由于我将NixOS部署在内网里，端口映射需要DHCP分配一个稳定的IP地址。因此我在配置文件前端添加了是否启用DHCP的选项。

  • NixOS启用xrdp非常轻松，但要注意defaultWindowManager需要填写桌面环境对应的启动命令。

  • 尽管可以直接声明没有收录的zsh主题（比如powerlevel10k)，但因为nix不会自动为你下载它们，因此我使用手动方式管理主题。
