简介 ​

遗传算法是一种仿生学算法，通过模拟自然选择过程中基因的变异、遗传和选择来优化解决方案的算法。它对解的数学性质要求很低，因此可以克服传统搜索算法（比如模拟退火等）的局限性，跑一些参数量大、表示形式复杂、不光滑的问题。

核心思想 ​

  • 变异：个体性状会发生小的扰动
  • 遗传：子代性状大部分遗传自双亲
  • 选择：具有优良性状的个体存活几率大

具体化 ​

  • 基因：解的表示形式，每个基因型代表一个个体
  • 种群：基因集合或者说个体集合
  • 适应度：基因的评价指标，越高说明性状越优良（更优解）
  • 选择：迭代选择适应度高的个体，保留一部分适应度低的个体
  • 交叉：双亲部分基因片段互换
  • 突变：基因的随机（小规模）变化

流程图 ​

  1. 开始
  2. 创建初始种群
  3. 计算初始种群适应度
  4. 选择
  5. 交叉
  6. 突变
  7. 计算种群每个个体适应度
  8. 若未满足终止条件->4
  9. 选择适应度最高的个体
  10. 结束

其他 ​

精英主义 ​

选前n个最优适应个体进入下一轮迭代。

deap框架实践 ​

deap是一个广泛使用的遗传算法框架，通过类成员注册的方法灵活配置个体、种群的生成和算子的定义，帮助我们快速搭建遗传算法模型。

OneMax问题 ​

OneMax问题是指找出一个固定长度的01序列中1个数最多的解，算是遗传算法的Hello, world。

首先，引入deap: ​

python
import random
from deap import base, creator, tools, algorithms

base提供了基础的数据结构，creator提供了创建自定义类的方法，tools提供了有用的工具函数（比如预设的位反转、点交叉函数），algorithms提供预设好的算法（比如eaSimple代际遗传算法）。

注册适应度(Fitness)类和个体(Individual)类: ​

python
creator.create("FitnessMax", base.Fitness, weights=(1.0,))
creator.create("Individual", list, fitness=creator.FitnessMax)

deap.creator.create(name, type, member)接受三个参数，name表示自定义类的名字，type表示数据类型，member表示额外添加的成员/属性。

注册个体/种群生成器 ​

python
toolbox = base.Toolbox()
toolbox.register("get_bool", random.randint, 0, 1)
toolbox.register("individual", tools.initRepeat, creator.Individual, toolbox.get_bool, n=10)
toolbox.register("population", tools.initRepeat, list, toolbox.individual)

deap.base.Toolbox().register(name, func, parameters...)接受三个参数，name是注册名，func是函数，parameters为调用func的参数。如果parameters没有覆盖所有参数，在调用封装好的name时则需要补充上。

也就是说register是对某函数做了封装。这里，我们的意思是：

  1. 重复n=10次的random.randint(0,1)，
  2. 将结果填入creator.Individual中作为个体生成器的返回结果；
  3. 然后重复生成creator.Individual填入基础数据结构为list的种群population中。

值得一提的是，与下文要注册的算子不同，这里的name填写什么都可以，不要求特定的名称。

注册算子 ​

python
def evalOneMax(individual): 
    return (sum(individual), )

toolbox.register("evaluate", evalOneMax)
toolbox.register("mate", tools.cxTwoPoint)
toolbox.register("mutate", tools.mutFlipBit, indpb=0.10)
toolbox.register("select", tools.selTournament, tournsize=3)

toolbox的evaluate，mate，mutate，select是保留名，algorithms的特定算法如eaSimple会寻找这些名字的函数。

  • evaluate，评估。应当返回一个元组，该元组的结构与Fitness的定义相当
  • mate（也称为交叉，crossover）接受两个个体ind1、ind2，返回交叉后的两个个体ind1'、ind2'，注意deap提供的大多数交叉算子如cxTwoPoint都是原地修改的，所以eaSimple内部实际上是对父代的克隆进行操作。
  • mutate，变异。收到一个个体，返回一个个体，这里使用内置mutFlipBit，随机修改01list的百分之p位
  • select，选择。输入种群pop和筛选数量k，返回k个被选中的个体。

运行遗传算法 ​

python
pop = toolbox.population(n=50)
hof = tools.HallOfFame(10)
pop, logbook = algorithms.eaSimple(pop, toolbox, cxpb=0.5, mutpb=0.2,ngen=10, stats=stats,halloffame=hof, verbose=True)

先通过pop创建种群，再使用tools.HallOfFame来记录历史上最优秀的10个个体，运行内置代际遗传算法eaSimple（不含精英主义）。

代码及运行结果 ​

完整代码如下：

python
import random
from deap import base, creator, tools, algorithms

creator.create("FitnessMax", base.Fitness, weights=(1.0,))
creator.create("Individual", list, fitness=creator.FitnessMax)

# ind = creator.Individual([1,0,1,1,0])

toolbox = base.Toolbox()
toolbox.register("get_bool", random.randint, 0, 1)
toolbox.register("individual", tools.initRepeat, creator.Individual, toolbox.get_bool, n=10)
toolbox.register("population", tools.initRepeat, list, toolbox.individual)

# print(tools.initRepeat(creator.Individual, toolbox.get_bool, n=10))
# print(toolbox.individual())

def evalOneMax(individual): 
    return (sum(individual), )

toolbox.register("evaluate", evalOneMax)
toolbox.register("mate", tools.cxTwoPoint)
toolbox.register("mutate", tools.mutFlipBit, indpb=0.10)
toolbox.register("select", tools.selTournament, tournsize=3)

def main(): 
    import numpy 
    
    pop = toolbox.population(n=50)
    hof = tools.HallOfFame(10)
    stats = tools.Statistics(lambda ind: ind.fitness.values)
    stats.register("avg", numpy.mean)
    stats.register("min", numpy.min)
    stats.register("max", numpy.max)

    pop, logbook = algorithms.eaSimple(pop, toolbox, cxpb=0.5, mutpb=0.2,ngen=10, stats=stats,halloffame=hof, verbose=True)
    
    return pop, logbook, hof 

if __name__ == "__main__":
    pop, log, hof = main()
    print("Best individual is: %s\nwith fitness: %s" % (hof[0], hof[0].fitness))
    
    import matplotlib.pyplot as plt
    gen, avg, min_, max_ = log.select("gen", "avg", "min", "max")
    plt.plot(gen, avg, label="average")
    plt.plot(gen, min_, label="minimum")
    plt.plot(gen, max_, label="maximum")
    plt.xlabel("Generation")
    plt.ylabel("Fitness")
    plt.legend(loc="lower right")
    plt.show()
