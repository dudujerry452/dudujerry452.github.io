vim非常轻量, 我很喜欢, 我的vim配置可见于全部vim配置.

让我们先看看vimrc:

v
syntax on " enable lint

filetype plugin indent on

第一行开启语法高亮, 第二行启用了三个选项:

  • Filetype: 允许vim根据后缀检测文件类型
  • Plugin: 允许vim检测到某个文件类型时, 自动加载专属插件
  • indent: 开启文件类型专属缩进
v
"中文编码相关
set fileformat=unix " unix or DOS, determine line terminators
set fileencoding=utf8
" 自动判断编码时，依次尝试以下编码：
set fileencodings=ucs-bom,utf-8,gb18030,default
" gb18030 最好在 UTF-8 前面，否则其它编码的文件极可能被误识为 UTF-8

接下来, 设置打开文件时默认的编码:

  • Fileformat: 我们熟悉的CL/CR和\n
  • fileencoding: 从前往后按照优先级猜测编码. 注释写错了, 实际上utf-8容易被误认为gbk.
