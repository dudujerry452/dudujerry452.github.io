二、mpv 播放参数优化 ​

2.1 硬件解码选项 ​

VA-API（当前最佳）

bash
hwdec=vaapi
hwdec-codecs=all

自动选择（可能回退到软解）

bash
hwdec=auto-safe  # 安全模式，避免崩溃
hwdec=auto       # 激进模式，尝试所有硬解

强制 VA-API 并指定设备

bash
hwdec=vaapi
hwdec-codecs=all
gpu-context=wayland

2.2 解码优化参数 ​

跳帧优化（已在用）

bash
vd-lavc-fast=yes                    # 快速解码模式
vd-lavc-skiploopfilter=all          # 跳过环路滤波（降低质量但提升性能）
vd-lavc-skipframe=nonref            # 跳过非参考帧
vd-lavc-threads=4                   # 解码线程数（根据 CPU 核心数调整）

更激进的跳帧

bash
vd-lavc-skiploopfilter=all
vd-lavc-skipidct=nonref             # 跳过 IDCT
vd-lavc-skipframe=bidir             # 跳过双向预测帧

2.3 帧率限制 ​

限制到 30fps（已在用）

bash
vf=fps=30

限制到 24fps（更省资源）

bash

限制到 15fps（极端省资源，适合静态场景）

bash
vf=fps=15

2.4 视频输出优化 ​

使用 GPU 渲染

bash
vo=gpu                              # 使用 GPU 渲染（默认）

# 或
gpu-api=opengl                      # 使用 OpenGL

降低渲染质量

bash
profile=fast                        # 快速配置文件
scale=bilinear                      # 使用双线性缩放（最快）
dscale=bilinear                     # 降采样使用双线性
cscale=bilinear                     # 色度缩放使用双线性

禁用高级渲染特性

bash
deband=no                           # 禁用去色带
sigmoid-upscaling=no                # 禁用 sigmoid 升频
correct-downscaling=no              # 禁用正确降采样
linear-downscaling=no               # 禁用线性降采样

bash

九、故障排除 ​

问题 1：硬件加速不工作 ​

症状： CPU 占用 100%+，日志显示软解

解决：

# 检查 DRI 设备权限
ls -la /dev/dri/

# 确保用户在 video 组
groups | grep video

问题 2：视频卡顿 ​

症状： 播放不流畅，掉帧

解决：

bash
# 增加缓存
mpvOptions = [
  ...
  "cache=yes"
  "cache-secs=10"
  "demuxer-max-bytes=100M"
];

问题 3：转换后视频质量差 ​

症状： 转换后视频模糊或有伪影

解决：

bash
# 提高码率
-b:v 8M  # 从 5M 提高到 8M

# 使用更好的编码预设
-preset slow  # 编码慢但质量好

问题 4：mpvpaper 崩溃 ​

症状： mpvpaper 频繁退出

解决：

bash
# 使用 auto-safe 而不是 vaapi
hwdec=auto-safe

# 检查日志
journalctl --user -u mpvpaper -f
