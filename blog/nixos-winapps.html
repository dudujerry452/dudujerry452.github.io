什么是 WinApps ​

WinApps 是一个开源项目，允许在 Linux 上无缝运行 Windows 应用程序，就像它们是原生 Linux 应用一样。

核心特性：

  • Windows 应用显示为独立窗口（而非完整桌面）
  • 在应用启动器中直接显示 Windows 应用图标
  • 共享 Linux home 目录到 Windows
  • 支持文件关联（右键用 Windows 应用打开文件）
  • 支持所有 Windows 应用（除内核级反作弊系统）

后端支持：

  • Docker/Podman（推荐，自动化安装）
  • libvirt/KVM（本文方案，更灵活，性能更好）

NixOS 配置 ​

1. 创建模块文件 mods/win-apps.nix ​

nix
{ pkgs, inputs, ... }:

{
  # ── 虚拟化服务 ──────────────────────────────────────────
  virtualisation.libvirtd = {
    enable = true;
    qemu = {
      package = pkgs.qemu_kvm;
      swtpm.enable = true; # TPM 2.0 模拟（Windows 11 必需）
    };
  };

  # ── 创建 libvirt 组（WinApps 脚本需要，NixOS 默认用 libvirtd）──
  users.groups.libvirt = {
    members = [ "dudujerry" ];  # 改成你的用户名
  };

  # ── 确保 libvirt 默认网络自动启动 ──────────────────────
  systemd.services.libvirt-default-network = {
    description = "Autostart libvirt default network";
    after = [ "libvirtd.service" ];
    requires = [ "libvirtd.service" ];
    wantedBy = [ "multi-user.target" ];
    serviceConfig = {
      Type = "oneshot";
      RemainAfterExit = true;
    };
    script = ''
      sleep 2
      ${pkgs.libvirt}/bin/virsh net-info default >/dev/null 2>&1 || \
        ${pkgs.libvirt}/bin/virsh net-start default
      ${pkgs.libvirt}/bin/virsh net-autostart default
    '';
  };

  # ── VM 管理 GUI ────────────────────────────────────────
  programs.virt-manager.enable = true;

  # ── WinApps 及依赖 ────────────────────────────────────
  environment.systemPackages = [
    inputs.winapps.packages."x86_64-linux".winapps
    inputs.winapps.packages."x86_64-linux".winapps-launcher
    pkgs.freerdp      # FreeRDP v3
    pkgs.dialog       # TUI 对话框
    pkgs.netcat-openbsd
    pkgs.libnotify
  ];

  # ── 环境变量 ──────────────────────────────────────────
  environment.sessionVariables = {
    LIBVIRT_DEFAULT_URI = "qemu:///system";
  };
}

2. 在 configuration.nix 中导入模块 ​

nix
{
  imports = [
    ./mods/win-apps.nix
  ];

  # 确保用户在必要的组中
  users.users.你的用户名 = {
    extraGroups = [ "libvirtd" "kvm" ];
  };
}

3. Home Manager 配置（可选） ​

在 home/winapps-env.nix 中配置：

nix
{ config, pkgs, ... }:

{
  home.activation.initWinappsConfig = config.lib.dag.entryAfter [ "writeBoundary" ] ''
    dir="$HOME/.config/winapps"
    file="$dir/winapps.conf"
    if [ ! -f "$file" ]; then
      mkdir -p "$dir"
      cat > "$file" << 'EOF'
##################################
#   WINAPPS CONFIGURATION FILE   #
##################################

RDP_USER="win"              # Windows 用户名
RDP_PASS="your_password"    # Windows 密码
RDP_DOMAIN=""
VM_NAME="RDPWindows"        # 虚拟机名称（必须一致！）
WAFLAVOR="libvirt"
RDP_SCALE="100"
RDP_FLAGS="/cert:tofu /sound /microphone +home-drive"
AUTOPAUSE="on"              # 5分钟不活动自动暂停
AUTOPAUSE_TIME="300"
DEBUG="true"
EOF
      chmod 600 "$file"
    fi
  '';
}

创建 Windows 虚拟机 ​

1. 镜像选择：Tiny11 ​

推荐使用 Tiny11（精简版 Windows 11）：

  • 体积小（~4-5 GB，官方版 10+ GB）
  • 启动快，资源占用低
  • 移除了不必要的组件（Edge、小组件、OneDrive 等）
  • 完全支持 RDP 和所有桌面应用

下载： 搜索 "Tiny11" 获取 ISO 文件

注意： virt-manager 无法自动检测 Tiny11，需要手动选择操作系统类型为 "Windows 11"。

2. 使用 virt-manager 创建虚拟机 ​

虚拟机创建步骤 ​

  1. 启动创建向导

    • virt-manager → "+" 图标
    • 选择 "Local install media (ISO image)"

  2. 选择 ISO

    • Browse → 从 Browse Local 选择 Tiny11 ISO
    • 取消勾选 "Automatically detect"
    • 手动搜索选择 "Microsoft Windows 11"

  3. 配置资源

    • 内存： 4096 MB（4 GB，Tiny11 最低 2 GB）
    • CPU： 2-4 核心

  4. 创建虚拟磁盘

    • 大小：50-60 GB（推荐）
    • 格式：qcow2（默认，按需分配）
      • 优势：只占用实际使用的空间
      • 50 GB 虚拟磁盘初始只占 10-15 GB
      • 支持快照功能

  5. 设置虚拟机名称

    • 重要： 名称必须是 RDPWindows（与配置文件一致）
    • 勾选 "Customize configuration before install"

  6. 自定义配置（推荐）

    • Display: 改为 Spice 或 VNC
    • Video: 改为 Virtio 或 QXL
    • 磁盘总线: 改为 VirtIO（更好的性能）
    • 网络: 确保选择 default NAT

  7. 开始安装

    • 按照 Windows 安装向导完成安装
    • 安装过程中可能会提示 Windows 更新（可跳过或安装）

网络配置 ​

libvirt 默认 NAT 网络：

网段：192.168.122.0/24
网关：192.168.122.1（宿主机）
DHCP：192.168.122.2 - 192.168.122.254
功能：虚拟机可访问外网，宿主机可访问虚拟机

验证网络：

bash
sudo virsh net-list --all
# 应显示：default   active   yes

Windows 端配置 ​

安装完 Windows 后，必须完成以下配置：

1. 启用远程桌面（RDP） ​

方法 1：PowerShell（管理员）

powershell
# 启用 RDP
reg add "HKLM\System\CurrentControlSet\Control\Terminal Server" /v fDenyTSConnections /t REG_DWORD /d 0 /f

# 禁用 NLA（网络级别身份验证）
reg add "HKLM\System\CurrentControlSet\Control\Terminal Server\WinStations\RDP-Tcp" /v UserAuthentication /t REG_DWORD /d 0 /f

# 允许 RDP 通过防火墙
Enable-NetFirewallRule -DisplayGroup "Remote Desktop"

# 重启 Terminal Services
Restart-Service TermService -Force

方法 2：GUI

设置 → 系统 → 远程桌面 → 启用远程桌面
点击"高级设置" → 取消勾选"要求计算机使用网络级别身份验证..."

2. 配置用户账户 ​

  • 创建本地用户（例如：win）
  • 必须设置密码（WinApps 需要）
  • 账户类型：管理员

验证：

powershell
net user win

3. 导入 WinApps 注册表配置 ​

注意，此时还没进行winapps安装，所以方法1大概率是用不了的

方法 1：通过共享驱动器

  1. 在文件资源管理器地址栏输入：

    \\tsclient\home\winapps\oem\

  2. 双击 RDPApps.reg → 点击"是"导入

方法 2：手动运行命令

powershell
# 禁用 RemoteApp allowlist - 关键！
reg add "HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Terminal Server\TSAppAllowList" /v fDisabledAllowList /t REG_DWORD /d 1 /f

# 允许未列出的程序
reg add "HKLM\SOFTWARE\Policies\Microsoft\Windows NT\Terminal Services" /v fAllowUnlistedRemotePrograms /t REG_DWORD /d 1 /f

# 重启服务
Restart-Service TermService -Force

配置说明：

  • 这些注册表项允许 WinApps 通过 RAIL (Remote Application Integrated Locally) 模式运行任意 Windows 应用
  • 没有这些配置，RDP 连接会失败并报错 RAIL_EXEC_E_NOT_IN_ALLOWLIST

4. 关闭防火墙（可选） ​

对于本地虚拟机，可以完全关闭防火墙简化配置：

控制面板 → Windows Defender 防火墙 → 启用或关闭防火墙
关闭所有网络的防火墙

5. 完成配置后登出 ​

重要： RDP 连接要求用户已登出。配置完成后：

  1. 点击开始菜单 → 登出（Sign out）
  2. 不要只关闭 virt-manager 窗口

WinApps 安装与配置 ​

1. 配置文件 ​

编辑 ~/.config/winapps/winapps.conf：

bash
RDP_USER="win"                    # 你在 Windows 中创建的用户名
RDP_PASS="your_password"          # 密码
VM_NAME="RDPWindows"              # 虚拟机名称（必须一致）
WAFLAVOR="libvirt"                # 后端类型

2. 运行安装脚本 ​

bash
cd ~/winapps
sg libvirt -c "./setup.sh --user"

安装过程：

  1. 检查依赖和组权限
  2. 检查虚拟机状态
  3. 测试 RDP 连接
  4. 扫描 Windows 中已安装的应用
  5. 创建 Linux 应用启动器

安装位置：

  • 脚本：~/.local/bin/winapps-src/
  • 启动器：~/.local/share/applications/
  • 图标：~/.local/share/winapps/icons/

3. 常见安装问题 ​

问题 1：组权限错误 ​

ERROR: The current user is not part of group 'libvirt' and/or 'kvm'

原因： NixOS 使用 libvirtd 组，而 WinApps 检查 libvirt 组。

解决： 在 mods/win-apps.nix 中添加（已包含在上述配置中）：

nix
users.groups.libvirt = {
  members = [ "你的用户名" ];
};

问题 2：RDP 连接失败 ​

ERROR: REMOTE DESKTOP PROTOCOL FAILURE

排查步骤：

  1. 检查虚拟机状态：

    bash
    virsh list
virsh domifaddr RDPWindows
nc -zv 192.168.122.177 3389  # 测试 RDP 端口

  2. 检查 Windows 配置：

    • RDP 是否启用？
    • NLA 是否已禁用？
    • 用户是否已登出？
    • 防火墙是否允许 RDP？

  3. 删除旧证书：

    bash
    rm -f ~/.config/freerdp/server/*.pem

  4. 重启虚拟机：

    bash
    virsh reboot RDPWindows
sleep 90  # 等待启动

问题 3：证书验证失败 ​

ERROR: Certificate verification failure

解决： 配置文件中的 /cert:tofu 应该自动接受证书，如果仍失败：

bash
rm -rf ~/.config/freerdp/server/

使用方法 ​

1. 打开 Windows 桌面 ​

bash
~/.local/bin/winapps windows

或在应用启动器中搜索 "Windows"。

2. 安装 Windows 应用 ​

在 Windows 桌面中安装你需要的应用：

  • 内置应用： 记事本、画图、计算器
  • Office 套件： Word、Excel、PowerPoint
  • 第三方软件： Chrome、Adobe Reader、VSCode 等

3. 扫描新安装的应用 ​

bash
cd ~/winapps
sg libvirt -c "./setup.sh --user --add-apps"

WinApps 会自动：

  1. 通过 RDP 连接到 Windows
  2. 扫描已安装的应用
  3. 在 Linux 应用启动器中创建对应图标

4. 启动 Windows 应用 ​

安装后，可以：

  • 在应用启动器中搜索应用名称（如 "Excel"）
  • 应用会在独立窗口中打开（无需完整桌面）
  • 看起来就像原生 Linux 应用

5. 文件关联 ​

右键点击文件（如 .docx）→ "打开方式" → 选择 Word

6. 虚拟机管理 ​

bash
# 查看状态
virsh list

# 启动虚拟机
virsh start RDPWindows

# 关闭虚拟机
virsh shutdown RDPWindows

# 强制关闭
virsh destroy RDPWindows

# 重启虚拟机
virsh reboot RDPWindows

# 自动暂停（配置中已启用）
# 5分钟不活动自动暂停，节省资源

常见问题 ​

Q1: 为什么找不到共享驱动器？ ​

A: 共享驱动器 \\tsclient\home 不在"网络"中。

访问方法：

  1. 在文件资源管理器地址栏直接输入：\\tsclient\home
  2. 或在"此电脑"中查找"home on ..."网络驱动器
  3. 必须在 RDP 会话内才能访问（这是 RDP 的虚拟设备重定向）

Q2: 虚拟硬盘如何扩容？ ​

A: qcow2 格式默认按需分配，后期可扩展：

bash
# 1. 关闭虚拟机
virsh shutdown RDPWindows

# 2. 扩展虚拟硬盘（例如增加 30GB）
qemu-img resize /path/to/RDPWindows.qcow2 +30G

# 3. 启动虚拟机，在 Windows 中：
#    磁盘管理 → 右键 C: 盘 → 扩展卷

Q3: 如何优化性能？ ​

  1. 使用 VirtIO 驱动：

    • 下载 virtio-win ISO
    • 在 Windows 中安装 virtio-win-guest-tools.exe

  2. 调整 CPU 固定：

    • 在 virt-manager 中固定特定 CPU 核心
    • 减少上下文切换，提高缓存利用率

  3. 关闭不必要的 Windows 服务：

    powershell
    Get-Service | Where-Object {$_.StartType -eq 'Automatic'} | Out-GridView

Q4: Docker vs libvirt 如何选择？ ​

特性Docker/Podmanlibvirt/KVM
安装难度简单（自动化）复杂（手动）
性能较好最佳（硬件虚拟化）
兼容性有限制完整 Windows 环境
资源占用较小较大
定制性低高
推荐场景快速测试日常使用

Q5: 卸载 WinApps ​

bash
cd ~/winapps
sg libvirt -c "./setup.sh --user --uninstall"

总结 ​

通过 libvirt + KVM 方案配置 WinApps：

优势：

  • ✅ 完整的 Windows 环境，兼容性最好
  • ✅ 硬件虚拟化，性能接近原生
  • ✅ 高度可定制（GPU 直通、USB 等）
  • ✅ 支持 Tiny11 等精简版系统

劣势：

  • ❌ 配置相对复杂
  • ❌ 需要手动安装 Windows
  • ❌ 资源占用较大

适用场景：

  • 需要长期使用 Windows 应用
  • 需要完整的 Windows 功能
  • 对性能和兼容性有要求
  • 愿意投入时间进行配置
