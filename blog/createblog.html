记录一下自己是如何搭建这个博客

本地搭建 ​

首先在本地搭建好Hexo框架。步骤如下：

安装node.js

For Mac

Bash
$ brew install node@20

For Linux

Bash
$ curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.0/install.sh | bash
$ nvm install 20

For Windows

PowerShell
$ wget https://nodejs.org/dist/v20.18.0/node-v20.18.0-x64.msi

安装时请坐和放宽，接下来输入

Bash
$ node -v 
$ npm -v

如果没有得到对应的版本号，说明这时需要手动设置环境变量了。

设置好后，安装hexo框架：

Bash
$ npm install hexo -g # -g意为全局安装

Hexo是一个博客的模板框架，不需要自己实现css和pug，就可以搭建出像我这么美观的博客。

全局的事情都做完了，现在应该建立一个文件夹了，这将是存储你的博客工程文件的地方，如果日后需要同步工程文件，就在这里git init；在命令行中进入它，然后输入：

Bash
$ npm install hexo-deployer-git --save #方便Hexo直接部署到github pages上
$ npm install hexo-renderer-pug hexo-renderer-stylus --save #一会装主题要用到的神奇妙妙工具

在根目录运行

Bash
$ hexo g && hexo s

如果提示没有异常，就可以在浏览器地址栏输入localhost:4000来观赏本地部署的博客啦~

新建博客则需要

Bash
$ hexo new 博客名

然后在/source/_posts就会生成对应名字的.md文件，使用Markdown编写博文； 此外可以根据自己的喜好配置一下根目录下的_config.yml，接下来是安装主题

Bash
$ cd ./themes
$ git clone https://github.com/jerryc127/hexo-theme-butterfly.git themes/butterfly
$ mv ./butterfly/.git ./butterfly/.git.bak #这一步不是必须的，只有在建立工程存储库时需要

butterfly的配置文件在/themes/butterfly/_config.yml，也是根据需要修改。这里非常建议在博客根目录下复制一份，并重命名叫_config.butterfly.yml，这个设置将覆盖butterfly主题下的_config，更解耦。具体的修改我参考的是这篇。

这样，再次运行

BASH
$ hexo g && hexo s

就可以看到设置的成果了。

github部署 ​

在github创建新的存储库，库名使用"用户名.github.io"，这也是你的博客将会被托管到的地址；可见性选择Public；Create repositories！

此处假设读者已经可以自如地使用git对自己的存储库pull/push；如果你第一次使用github或者没有建立自己的存储库，这里需要参照网上的教程设置好ssh key

接下来在根目录下_config.yml的deploy位置进行如下修改：

yml
deploy:
  type: git
  repository: git@github.com:用户名/用户名.github.io.git
  branch: main

保存退出，输入

Bash
$ hexo d

你的页面就会被上传到你创建的存储库，而你可以通过访问 你的用户名.github.io来看到和分享你的博客了！（从上传到看到之间可能间隔数十秒甚至几分钟）

额外修改 ​

数学公式 ​

另外，对于需要插入数学公式的用户，需要：

一、替换hexo的markdown渲染引擎

sh
npm uninstall hexo-renderer-marked --save
npm install hexo-renderer-kramed --save

二、编辑根目录下的_config.yml文件，在末尾中添加如下代码

yml
kramed:
  gfm: true
  pedantic: false
  sanitize: false
  tables: true
  breaks: true
  smartLists: true
  smartypants: true

三、在_config.butterfly.yml中设置

mathjax:
  enable: true
  per_page: true

此外，还有_等无法正确渲染的问题，需要修改npm包来解决，见参考文献[4]

自定义标题样式 ​

我希望文章预览的标题能根据Front-Matter不同选项有不同的css效果，于是修改butterfly的pug文件：

一、 打开themes/butterfly/layout/includes/mixins/indexPostUI.pug，找到

pug
a.article-title(href=url_for(link) title=title)

二、 修改这一行，为其添加一个条件类。我们将检查 article['how-to'] 是否为真，如果是，就添加一个名为 how-to-post-title 的类。

pug
a.article-title(href=url_for(link) title=title, class={'how-to-post-title': article['how-to']})

三、 在博客的source文件夹里新建css文件夹，新建custom.css，写入:

css
.how-to-post-title {
  color: #888 !important; /* 标题变为灰色 */
}

四、 修改_config.butterfly.yml，注入样式:

yml
inject:
  head:
    - <link rel="stylesheet" href="/css/custom.css">

五、 这样设置以后，在文章的Front-Matter栏填写how-to: true即可将标题预览变为灰色。

隐藏某些posts ​

安装插件

sh
npm install hexo-hide-posts --save
yml
# hexo-hide-posts configuration
hide_posts:
  enable: true
  filter: hidden
  public_generators: # <-- 添加这个配置项
    - archive
    - category
    - tag
    # - sitemap (如果使用sitemap插件，也建议加上)
    # - feed (如果使用feed插件，也建议加上)

这样，被打上hidden标签的post就不会在除了archive, category, tag页面之外显示（比如主页面）

解决首页标签，友链等404问题 ​

观察_config.butterfly.yml，有

yml
menu:
  首页: / || fas fa-home
  归档: /archives/ || fas fa-archive
  标签: /tags/ || fas fa-tags
  目录: /categories/ || fas fa-folder-open
  列表||fas fa-list:
    杂谈: /categories/杂谈/ || fas fa-music
    电影: /movies/ || fas fa-video

对于无法打开的url，比如tags，需要创建该类型页面：

sh
hexo new page tags

会提示创建了source/tags/index.md。此时修改index.md的front-matter，添加type: "tags"，即可将该页面识别为该index，其他url同理。对列表，里面的子项若想跳到某类型页面的下一级，比如分类中的“杂谈”，就需要在url后面加一级。

fas fa-music是图标，可改可不改。

解决下划线的mathjax与markdown冲突问题 ​

下划线有时候被优先被识别为markdown，被翻译为em标签，进而不会交给mathjax识别。这个问题有很多人讨论过，比较直接的一个办法是修改npm包源码来禁用对下划线的识别，但这样的修改不会被git记录，不方便我们长期维护。

折衷的办法是在识别失败的公式上下添加

{% raw %}
$$
f(x_1, x_2, \ldots, x_n) = \sum_{i=1}^{n} w_i x_i + b
$$
{% endraw %}

阻止markdown引擎对这段公式的识别。
